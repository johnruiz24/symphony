📊 Real-Time Architecture

SSE Streaming (Events)

The frontend maintains an open SSE connection that streams real-time updates from the backend:

task_created task_updated task_deleted task_reassigned agent_state_changed agent_workload_changed snapshot

Reconnection Strategy:
Exponential backoff (1s → 2s → 5s → 10s) with 10s polling fallback

Data Flow

User Action (UI) ↓ React Hook (optimistic update) ↓ TanStack Query (mutation) ↓ Vite Proxy → Backend API (:4000) ↓ Elixir Task Store ↓ Broadcast SSE Event ↓ Frontend SSE Hook ↓ React State Update → UI Re-render
